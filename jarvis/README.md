# JARVIS

Run it from the parent [README](../README.md).

Windows: `start-windows.bat`

Mac: `start-mac.command`

Linux: `start-linux.sh`

The server listens only on `127.0.0.1:4173`. Sensor readings stay on the machine. A missing fan speed or GPU temperature is labeled unavailable and the answer continues from the readings that exist.

Gaming PCs and gaming laptops get a free settings plan and a paid parts plan. A Mac, and a ThinkPad without a separate GPU, get the live readings and only the steps that machine can actually do.
