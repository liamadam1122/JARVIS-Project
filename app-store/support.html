JARVIS Support

Support for JARVIS, the free Mac app that shows CPU, memory, and the thermal state of this Mac, then answers questions on the Mac itself.

This page is the support page for the Mac App Store app. The app needs macOS 14 or later. It does not need an Apple ID inside the app, a subscription, a payment, or an internet connection.

How to use JARVIS

  1. Open JARVIS from the Applications folder.
  2. Read the sidebar. CPU and Memory are percents. The line under them shows the Mac model, the installed memory, and the thermal state macOS reports: Nominal, Fair, Serious, or Critical.
  3. Type a question, or choose “Optimize this Mac”, “Why does it feel warm?”, or “What can you read on this Mac?”.
  4. Read the reply. A question about heat or speed starts with a free plan. A paid plan, when it appears, is advice about hardware. JARVIS does not sell hardware, does not unlock a paid feature, and does not ask for a card.
  5. Start another chat with New conversation. Remove one with Delete.

What the numbers mean

  • CPU is how busy the processor has been since the last sample, as a percent from 0 to 100.
  • Memory is an estimate of used memory as a percent of the memory installed in the Mac.
  • Thermal state is the state macOS already publishes. JARVIS does not invent a temperature in degrees.

Right after launch, CPU or memory can say Unavailable for a few seconds. Ask again after that. If a reading is missing, the app says so.

What this version can show

The Mac App Store version can read the Mac model, installed memory, CPU load, a memory-use estimate, the system thermal state, and the names of up to five open apps. Replies are written on the Mac from those readings and from the words in the question. Chats stay on the Mac.

This version does not read websites, browser tabs, documents, or file names. It does not change settings, close apps, or repair the Mac. Fan speed and GPU temperature are not in this version. A MacBook Air has no fan for an app to report.

Delete your chats

Click Delete next to a conversation in the sidebar. That removes that conversation from this Mac. Removing JARVIS from the Mac removes the chats the app stored. There is no account to close and no cloud copy to delete, because this version does not upload chats.

If something looks wrong

  • The window stays empty or the numbers stay unavailable. Quit JARVIS and open it again from Applications. Wait a few seconds.
  • The Mac feels warm while the thermal state says Nominal. Ask “Why does it feel warm?”. The free steps are: close the heaviest open app, put the Mac on a hard surface, and keep the vents clear. Then ask again and compare the thermal state.
  • A reply names an open app. That is the app’s display name on this Mac. JARVIS does not see the website or file inside that app.
  • You expected fan speed or a GPU temperature. Those readings are not part of the Mac App Store version.
