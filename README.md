# Developer Learning

This repository is building JARVIS as a local-first assistant that understands the computer it runs on. Its focus is evidence-backed system insight—hardware, storage, processes, and network—not generic app-building help.

## Start here

- Follow [START_HERE.md](START_HERE.md) for the learning workflow.
- Explore [JARVIS](jarvis/README.md) for the local assistant interface and optional read-only telemetry bridge.
- Read the [build plan](JARVIS_BUILD_PLAN.md) and [telemetry design](JARVIS_TELEMETRY_DESIGN.md) for the staged roadmap and hardware-reading limits.

JARVIS chat replies are still demo responses; no model API is connected. Telemetry does not need an API key. Never commit API keys, passwords, or tokens.
