# Start Here

This repository is your practice space for learning how to build apps.

## The simple idea

- **ChatGPT:** help plan, explain code, find bugs, and review changes.
- **GitHub:** stores your project files online and tracks changes.
- **Codex or another coding tool:** can help write and edit code.

## The 4 words to know

- **Repository (repo):** the project folder on GitHub.
- **File:** one document or piece of code inside the project.
- **Commit:** a saved snapshot of changes, with a short message explaining them.
- **README:** the front page that explains what a project is.

## How we will work

1. You tell me what you want to build.
2. I explain the next step in plain language.
3. When appropriate, I can create or edit files in this repository through the GitHub connection.
4. We check what changed and test it before moving on.

## First mission

Do not worry about learning everything at once. First, learn how files and commits work. Then we can make a tiny working project and build it up one step at a time.

**Important:** Never put passwords, API keys, private tokens, or other secrets in this repository.
